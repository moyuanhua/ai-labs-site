<section>
  <p>
    建站是个重复性很高的工作。 landing page、产品官网、活动页，
    结构大同小异，但每次都要从零开始。
    这个案例讲的是如何把建站流程系统化，配合 AI 生成，把交付周期从周级缩到天级。
  </p>

  <h2>背景</h2>
  <p>
    团队经常需要快速搭建各类网站：
  </p>
  <ul>
    <li>产品 landing page</li>
    <li>活动页（限时活动、发布会）</li>
    <li>品牌官网</li>
    <li>文档站</li>
  </ul>
  <p>
    传统建站的问题：
  </p>
  <ul>
    <li>每次都要重新设计、重新开发，重复劳动多</li>
    <li>设计稿到代码的转换耗时长</li>
    <li>SEO、性能优化每次都要重新做</li>
    <li>交付周期长，通常 1-2 周起步</li>
  </ul>

  <h2>流程拆解</h2>
  <p>
    把建站流程拆成几个标准化步骤：
  </p>
  <ol>
    <li><strong>需求收集</strong>：明确目标、受众、核心内容</li>
    <li><strong>内容准备</strong>：文案、图片、视频等素材</li>
    <li><strong>设计</strong>：页面布局、视觉风格</li>
    <li><strong>开发</strong>：HTML/CSS/JS 实现</li>
    <li><strong>优化</strong>：SEO、性能、可访问性</li>
    <li><strong>部署</strong>：上线、监控</li>
  </ol>

  <h2>AI 介入点</h2>
  <p>
    在每个环节引入 AI：
  </p>
  <ul>
    <li><strong>内容生成</strong>：用 AI 生成初稿文案，人工润色</li>
    <li><strong>设计辅助</strong>：用 AI 生成设计稿或 HTML 原型</li>
    <li><strong>代码生成</strong>：用 AI 直接生成 HTML/CSS/JS</li>
    <li><strong>SEO 优化</strong>：用 AI 生成 meta 标签、结构化数据</li>
    <li><strong>图片处理</strong>：用 AI 生成配图、压缩图片</li>
  </ul>

  <h3>关键工具链</h3>
  <ul>
    <li><strong>Astro</strong>：静态站点生成器，性能好，SEO 友好</li>
    <li><strong>Tailwind CSS</strong>：快速样式开发，不用写 CSS 文件</li>
    <li><strong>AI 代码生成</strong>：Cursor / Claude / GPT-4o</li>
    <li><strong>图片生成</strong>：Midjourney / DALL-E / Stable Diffusion</li>
    <li><strong>部署</strong>：Vercel / Cloudflare Pages / GitHub Pages</li>
  </ul>

  <h2>效果</h2>
  <p>
    【待补充：具体提效数据，例如】
  </p>
  <ul>
    <li>交付周期：【待补充：从 X 天缩短到 Y 天】</li>
    <li>开发时间：【待补充：减少 X%】</li>
    <li>设计时间：【待补充：减少 X%】</li>
    <li>站点性能：【待补充：Lighthouse 分数 X+】</li>
  </ul>

  <h2>经验总结</h2>
  <ul>
    <li><strong>模板化</strong>：把常见的页面结构抽象成模板，下次直接复用</li>
    <li><strong>组件化</strong>：把常用的 UI 组件（hero、feature、pricing、footer）做成可复用组件</li>
    <li><strong>内容优先</strong>：先确定内容，再做设计。不要反过来</li>
    <li><strong>AI 生成初稿</strong>：让 AI 生成 80% 的代码，人做 20% 的调整</li>
    <li><strong>自动化部署</strong>：push 到 git 就自动部署，不要手动操作</li>
    <li><strong>性能预算</strong>：设定性能指标（如 LCP < 2.5s），CI 里自动检查</li>
  </ul>

  <blockquote>
    建站不是艺术创作，是<strong>工程问题</strong>。
    工程问题就要用工程方法解决：标准化、自动化、可复用。
  </blockquote>

  <p>
    这套流程已经帮团队快速交付了多个站点。
    核心思路就是：<strong>把重复的工作交给工具和 AI，人专注于创意和决策</strong>。
  </p>
